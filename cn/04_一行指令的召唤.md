# 第二篇　开机仪式

# 第4章　一行指令的召唤：从 Linux 到 Windows 原生

## 开源管家，养在自己的电脑上

在动手之前，先把一件事说清楚：Hermes Agent（以及龙虾）的本质，是「**让你把一个 AI 助理养在自己电脑上的开源工具**」。你的对话记录、你的技能、你的记忆，都存在你自己的机器里，而不是某家公司的云端。这是「自架（self-hosted）」的内核精神，也是这一整本书谈的所有自动化能成立的前提——**因为它跑在你的环境里，它才能真正帮你做事，而不只是聊天。**

## 类 Unix 环境：一行 curl 搞定

如果你在 **Linux、macOS、WSL2 或 Termux** 环境，安装就是字面意义上的「一行指令」。在终端机粘贴官方的安装脚本：

```
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | sh
```

（社群与官方文档中也常见到直接指向 GitHub 的等价脚本：`https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh`。）

装完之后，跑一次引导设置：

```
hermes setup
```

它会一步步带你配置两件最关键的事：**你的 AI 模型**（要地端的 Ollama／Gemma／Llama，还是云端的 OpenAI／Claude）、以及**你的通信平台**（例如把它接上你的 Telegram）。设置完，你就有了一个随时待命、住在你终端里的管家。

## Windows 原生：终于摆脱 WSL2 的枷锁

过去，Windows 用户要养这类 Agent，几乎都得先装 WSL2、Docker 或 Cygwin，门槛不低。**这件事已经改变了。**

Nous Research 官方已为 Windows 平台进行重构，解决了过去的字符编码（UTF-8）与 Shell 指令兼容性问题，让 CLI、TUI 交互接口、通信闸道（Gateway）以及「AI 自主编写技能」等内核功能，都能在 **Windows 10／11 上原生、无感启动**——**完全不需要 WSL2、Docker 或 Cygwin**。

你有两条最简单的路：

### 方法一・终端机一键安装（PowerShell）

打开 **Windows Terminal**（不需要系统管理员权限），拷贝粘贴官方的 Windows 原生安装指令：

```
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

这个脚本会自动把程序隔离安装在 `%LOCALAPPDATA%\hermes\` 路径下，并自动配置所需的 **Python、Node.js 独立环境**，甚至内置一份轻量化的 **PortableGit（约 45MB）**，用来在背景无感运行 AI 产生的 Shell 指令。装完，重开一个 PowerShell 窗口就能用。

### 方法二・桌面图形接口（Hermes Desktop）

如果你完全不想碰命令行，社群与官方也推出了 **Hermes Desktop**——下载 Windows 专用安装档、运行即可。首次启动时，它会在背景自动调用上述脚本，帮你把所有兼容环境配好。之后你就能在一个精美的窗口接口（WebUI）里直接切换模型、管理 AI 的记忆、添加技能。

## ⚠️ 一个你必须知道的小限制

Windows 原生版的完整度已经非常高，但有一个先天差异值得先摆在台面上：

**如果你的主要目的，是让 Agent 帮你「深度控制 Windows 系统、修改本地复杂的项目代码依赖」**——由于 Windows 的系统路径与 POSIX（Linux）环境先天不同，AI 在运行复杂的本地自动化指令时，偶尔仍可能踩到微小的 Bug。

所以官方的建议很务实：

| 你的身分 | 建议环境 | 理由 |
|---------|---------|------|
| 纯开发者（要 Agent 改 code、跑复杂本地自动化） | **WSL2** | 在终端自动化与程序项目集成上最为流畅 |
| 日常用户（通信管家、数据整理、串云端 API） | **Windows 原生** | 已经完全够用且非常稳定 |

> 💡 君之一席话
> **安装门槛的崩塌，往往比功能本身更能决定一个工具的命运。**
> 当「养一只会自己写程序的 AI」从「先学会配 WSL2 + Docker」变成「贴一行 PowerShell」，这个工具的潜在用户就从几万名工程师，瞬间扩张成几亿名 Windows 用户。技术的普及，常常不是赢在更聪明，而是赢在更好装。
