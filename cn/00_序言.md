## 序　当「养龙虾」变成一句叹息

二〇二五年底，一只「龙虾」在 GitHub 上爆红。

它的本名叫 **OpenClaw**，由开发者 steipete 发起，是一套基于大型语言模型的开源 AI 代理（AI Agent）框架。因为英文 *Claw*（爪）的谐音与社群的暱称，大家亲切地叫它「龙虾 🦞」。一时之间，「在自己电脑上养一只龙虾」成了开发者圈的显学——有人专门提供「龙虾安装服务」，帮你部署环境、调参数；没过多久，连「龙虾卸载服务」都出现了。

卸载服务的出现，本身就是一个耐人寻味的信号。

因为人们很快发现，龙虾虽然能同时串起 Telegram、LINE、Slack、微信等二十几种通信软件，背后又靠着庞大的社群技能库 ClawHub 快速接上各种网络服务，**广度惊人**；但它有两个致命的痛点：**它每天都失忆**——昨天教过它的偏好，今天就忘光；以及随着生态扩大，社群插件里开始混入恶意代码，系统又频繁更新、动不动就崩。于是每次对话都要重新喂一遍上下文，Token 费用居高不下；每次更新都像拆炸弹。

就在龙虾撞上瓶颈时，网络上悄悄刮起一股「**弃虾养马**」的风潮。

那匹「马」，是由知名 AI 研究机构 **Nous Research** 推出的 **Hermes Agent（爱马仕 🐴）**。它的官方标语只有一句话——**「The agent that grows with you」（与你一同成长的代理）**。它最大的亮点，是会把每一次帮你解过的复杂任务，自动萃取、整理成一份「技能文档（Skill File）」，下次遇到类似的活，直接调用，不必你重讲一遍。**越用越省钱，越用越聪明。**

---

这本书，就是写给站在这个十字路口的你。

它不是一篇行销文，也不是哪一边的传教手册。它想做三件事：

- **第一篇　两种哲学**：把龙虾与爱马仕拆开来看——不是比谁的功能多，而是看清它们背后两种**完全不同的设计信仰**：一个赌「广度与连接」，一个赌「深度与记忆」。看懂了哲学，你才知道自己该养哪一只。
- **第二篇　开机仪式**：一行指令如何把一个会自己写程序、自己跑指令的代理装进你的电脑——从 Linux／macOS／WSL2 到 Windows 原生，连坑都帮你标好。
- **第三篇　实战百景**：这才是全书的重头戏。我们借一位 **Google L7 Staff Engineer 兼资深 SRE** 的视角，走进分布式系统那片「布满地雷的沼泽」，看 Agent 如何在多云网络、金丝雀发布、混沌工程、资安黄金救援、FinOps 省钱、数据库死锁这些真实战场上，把「黑盒子猜测」变成「可视化决策」。

> 💡 这本书怎么读
> 每一个实战情境都用同一副骨架拆给你看：**背景 → 问题 → 需要的技能 → 需要的开源工具 → 用到的 Agent 特性 → 没有 Agent 为什么不方便 → 带来的效益**，最后再附上一句「君之一席话」的 take away。
> 你可以照顺序读完整套哲学，也可以直接翻到某个让你半夜睡不着的情境——每一景都自成一篇，独立成立。

技术会过时，框架会改名，龙虾和爱马仕说不定明年就被第三只动物取代。但这本书真正想留给你的，不是某个工具的安装指令，而是一个观念：

**自动化的尽头，不是「没有人」，而是「人只需要做最后那个决定」。**

翻过这一页，我们先从那场「弃虾养马」的世代交替讲起。
