# 附录B　开源工具速查

> 全书 300 个情境里反复出现的开源工具，依职能分类，附一句「它是什么／在书中扮演什么角色」。括号内为它在百景中最常被龙虾调用的场合。这份清单本身，就是一份现代 SRE / FA 工具箱的缩影。

## 可观测性（Observability）
| 工具 | 一句话定位 |
|------|-----------|
| **Prometheus** | 时序指针的事实来源；书中最常「被自己撑死」（基数爆炸）也最常当告警触发源 |
| **Grafana** | 把指针画成人看得懂的仪表板；龙虾推送的「可视化拓扑图」多半长在这里 |
| **Loki / Tempo / Jaeger** | 日志（Loki）、追踪（Tempo/Jaeger）三本帐；微服务盲测根因、Trace 比对的主力 |
| **OpenTelemetry** | 指针／日志／追踪的统一采集标准；跨语言埋点的共同语言 |
| **Thanos / Cortex** | 给 Prometheus 加上长期保存与全域视野的水平扩展层 |

## 编排、发布与自动扩缩
| 工具 | 一句话定位 |
|------|-----------|
| **Kubernetes（K8s）** | 容器编排的操作系统；几乎每个云端情境的底座 |
| **Argo Rollouts** | 金丝雀／蓝绿发布控制器；龙虾煞车「微量异常」发布时操作的对象 |
| **KEDA** | 事件驱动的自动扩缩；FinOps「下班制」缩容的运行手 |
| **Argo CD / Flux** | GitOps 部署；让「Git 是唯一事实来源」成立的关键 |

## 网络与服务网格
| 工具 | 一句话定位 |
|------|-----------|
| **Istio / Linkerd / Envoy** | 服务网格与 Sidecar 代理；流量染色、mTLS、限流的运行层 |
| **Cilium** | 基于 eBPF 的网络与安全策略；秒级下发 NetworkPolicy 隔离恶意 Pod |
| **FRRouting（FRR）/ BIRD / ExaBGP** | 开源 BGP 路由引擎；龙虾发动「防御性反向声明」夺回流量的武器 |
| **RPKI / RIPE NCC API** | 路由起源的密码学验证；对抗 BGP 劫持的合规底层 |
| **Cloudflare** | 边缘清洗与 Anycast 调度；天灾／DDoS 时的流量避风港 |

## 资安与供应链
| 工具 | 一句话定位 |
|------|-----------|
| **Falco** | 基于 eBPF 的运行期威胁侦测；反弹 Shell、勒索行为的第一个吹哨人 |
| **Wazuh** | 主机入侵侦测与日志审计；勒索软件「熵值飙高」告警的来源 |
| **Trivy** | 容器与依赖漏洞扫描；CVE 爆发时全库盲扫的扫描仪 |
| **OPA Gatekeeper / Kyverno** | K8s 策略即代码（Policy as Code）；拦截「秘密上线」未合规服务 |
| **HashiCorp Vault** | 密钥与凭证的集中保管与轮转；秒级熔断外泄密钥 |
| **cert-manager** | K8s 内凭证签发与续期；mTLS／HTTPS 不过期的守门人 |

## 保存与数据
| 工具 | 一句话定位 |
|------|-----------|
| **Ceph / MinIO / Rook** | 分布式对象／区块保存；书中常「空间突发归零」的受灾户 |
| **Longhorn** | K8s 原生分布式区块保存；卡载（Stuck Volume）解除的对象 |
| **PostgreSQL / MySQL / ProxySQL** | 关系数据库与读写分离代理；死锁、拷贝延迟的主战场 |
| **Redis** | 内存缓存与分布式锁；时钟漂移引发双写灾难的主角 |
| **etcd** | K8s 的大脑（集群状态库）；脑裂（Split-Brain）时最致命的单点 |
| **Elasticsearch / Logstash / Fluent Bit** | 日志索引与管线；GDPR 敏感数据脱敏的注入点 |

## 消息、运算与韧性
| 工具 | 一句话定位 |
|------|-----------|
| **Kafka** | 分布式消息骨干；跨云断电自愈、日志洪流削峰的内核 |
| **Spark / Flink** | 大数据批量／串流运算；数据倾斜（Straggler）的发生地 |
| **Resilience4j / Sentinel** | 熔断器与限流框架；「优雅降级」的代码级实作 |

## IaC、混沌与备援
| 工具 | 一句话定位 |
|------|-----------|
| **Terraform / Pulumi / Ansible** | 基础设施即代码（IaC）；组态漂移自动修正 PR 的目标格式 |
| **Chaos Mesh / Litmus** | 混沌工程注入框架；龙虾「紧急煞车」中止的对象 |
| **Velero** | K8s 集群备份与还原；灾后重建的安全网 |
| **Harbor** | 私有容器映像仓库；Docker Hub 限流时的备用镜像源 |

> 🔍 给动手派的一句提醒
> 这份清单里没有一个工具是「龙虾专属」的——它们都是你**现在就在用、或早该用**的成熟开源系统。Agent 的价值不是取代它们，而是当那个**懂得在对的时机、调用对的工具、串起对的人**的指挥官。先把工具箱备齐，Agent 才有东西可指挥。
